How Downtime Works

Scheduled downtime temporarily disconnects the Discord bot, while this website and the public Status page may remain available. A Discord API rate limit is a separate, unplanned condition. Administrators can edit the schedule in Dashboard → Access Control → Bot Offline Schedule. To learn more, see the Downtime documentation.
