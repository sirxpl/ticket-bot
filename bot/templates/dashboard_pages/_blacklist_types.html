Blacklist Roles

Configure the Discord roles that control ticket creation.

▾

Add a name and Discord role for each blacklist. Assign or remove these roles directly in Discord, including while the bot is offline. Members with an enabled blacklist role cannot create tickets. Disabled roles do not block ticket creation. Reasons are optional.

This is role-based across all ticket categories. Removing a role configuration does not delete legacy blacklist records; those remain available for review on the Blacklists page.
