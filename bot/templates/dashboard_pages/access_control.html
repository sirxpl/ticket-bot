Schedule when the Discord bot should appear offline. The dashboard and public status pages remain available. Each day can have multiple offline windows, and a window can cross midnight.

⚙️ Linked Roles (Discord Connections)

▾

Lets members verify by agreeing to the Rules & Regulations through Discord's own Connections screen — the bot shows up under "Apps" just like other Linked Roles integrations. Needs no privileged intents at all.

One-time setup in the Discord Developer Portal:
  1. Click "Register Metadata" below (do this first)
  2. Bot → General Information → set Linked Roles Verification URL to:
    {{ url_for('linked_role_start', _external=True) }}
  3. OAuth2 → add this redirect URL:
    {{ url_for('linked_role_callback', _external=True) }}
  4. In your Discord server: Server Settings → Roles → pick a role → Links tab → add a requirement for "Agreed to Rules"
